DevOps Roadmap

A practical order for building career-ready skills.

1

Foundation

  • Linux shell, files, users, permissions
  • Networking basics: DNS, HTTP, ports
  • Git branches, commits, pull requests
2

Scripting

  • Bash automation for repeated work
  • Python basics for tooling
  • Logs, exit codes, cron jobs
3

Cloud

  • Compute, storage, IAM, VPC concepts
  • Deploy one small app manually
  • Document costs and security choices
4

Delivery

  • Docker images, volumes, networks
  • CI pipelines for test and build
  • Infrastructure as code basics
5

Operations

  • Kubernetes workloads and services
  • Monitoring, alerts, incident notes
  • Backups, secrets, least privilege
